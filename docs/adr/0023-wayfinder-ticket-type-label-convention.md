# Wayfinder Ticket Type Label Convention

Every ticket under `D:\Projects/docs/tickets/` MUST carry a `**Type:**` line as the second line of the ticket markdown, formatted as `**Type:** wayfinder:<research|prototype|grilling|task> (<HITL|AFK>)`, where `<research|prototype|grilling|task>` is the wayfinder ticket type and `<HITL|AFK>` records whether resolution requires a human in the loop (`HITL`) or runs agent-alone (`AFK`); the convention was adopted after Spec 15 surfaced a gap where local tickets used only `Status:` / `Reasoning:` / `Blocked by:` frontmatter and silently omitted the type label the wayfinder skill at `D:\Projects\.agents\skills\wayfinder\SKILL.md:65` requires, leaving a mismatch with the public `Viello/agent-skills` catalog whose tickets carry the label inline. Tickets are typed at chart time and never silently retyped; the type may only change via a follow-up ticket that explicitly re-classifies and documents the change. The wayfinder skill at `D:\Projects\.agents\skills\wayfinder\SKILL.md` is patched to render the label onto every new ticket by default so future charts inherit the discipline without per-ticket opt-in. The convention is forward-looking only — tickets under `D:\Projects\.agent/archive/` retain their original format and are not retroactively retyped. The `Spec 15` ticket `T019` propagates the patched skill to `Viello/agent-skills` so the public catalog and the local vendor stay aligned; this ADR binds the propagation as part of the convention rather than treating it as an optional mirror.
