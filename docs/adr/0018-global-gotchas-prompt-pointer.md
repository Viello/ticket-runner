# Global Gotchas Prompt Pointer Pattern

To prevent Worker prompt sizes from exceeding the Windows operating system command-line limit (32,767 characters, raising `WinError 206`) and wasting startup context tokens as `docs/tickets/gotchas.md` grows across dozens of tickets, we decided to reference global gotchas via a scoped file pointer (`Review and adhere to all project-wide pitfalls recorded at docs/tickets/gotchas.md before implementing`) rather than inlining the entire markdown document verbatim. This mirrors our established prompt pointer patterns for execution skills (ADR 0008) and specs (ADR 0011), caps initial prompt overhead to ~2.5 KB regardless of repository gotcha history, eliminates unnecessary 43+ KB disk reads during prompt construction, and preserves the full token budget for active ticket implementation.
