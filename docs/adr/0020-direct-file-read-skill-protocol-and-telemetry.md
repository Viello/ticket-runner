# Direct File-Read Skill Protocol, Invariants Inlining, and Stream Telemetry

We decided that the Ticket Runner must direct the OpenCode Worker to consume project-local skills under `.agents/skills/` and repository rules in `AGENTS.md` through explicit file-reading tool instructions (`read(filePath="...")`) rather than relying on OpenCode's native skill tool or interactive slash-command syntax (`/code-review`, `/security-review`). To guarantee operational grounding, the Runner inlines the core `## Invariants` section from `AGENTS.md` directly into the Worker prompt alongside the Spec Excerpt. For observability and discipline enforcement, the Runner intercepts the Worker's JSONL event stream via structured `tool_use` event decoding and raw line matching, emitting soft warnings via the terminal and Discord if required review skills (`.agents/skills/code-review-ticket-runner/SKILL.md` and `.agents/skills/security-review-ticket-runner/SKILL.md`, as amended by ADR 0026) or `AGENTS.md` are bypassed before ready signaling while preserving independent Gatekeeper verification as the sole acceptance barrier.
