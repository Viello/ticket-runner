### Acceptance Criteria
- Worker prompt generated by `PromptBuilder.build` contains the pointer to `docs/tickets/gotchas.md` under `## Global Gotchas & Lessons Learned` and does not inline raw gotchas file content.
- `TicketProcessor._build_prompt` and `HandoffCoordinator.build_prompt` do not load `gotchas.md` content into memory to construct prompts.
- Total command length produced by `build_opencode_run_command` with real `docs/tickets/gotchas.md` on disk remains well below the Windows 32,767 character ceiling.
- Existing unit and spec test suites pass green.

### Gotchas
- Ticket IDs must strictly match `T\d{3,}` per domain rules; alphanumeric suffix IDs (e.g. `T034b`) violate `TICKET_ID_PATTERN`.
- When resolving `gotchas_path`, normalize to posix format (`/`) so the path renders consistently across platforms in markdown prompts.
- Do not remove `GotchasStore` from the container or Gatekeeper; `GotchasStore.append` is still required when completing tickets.
